# Radio-sensitivity-prediction using breast cancer genomic dataset.
This project contains code for the radio sensitivity predictions from genomic data of breast cancer patients. 
Breast cancer is become one of the most common tumor among the women majorly around the world. It is a challenging disease which occurs due the abnormal growth of the cells or tissues around the breast which slowly or gradually spreads throughout the body and can be lethal for the individual. Approximately 2.3 million women was diagnosed with the breast cancer and 670,000 deaths were caused globally in 2022.
Random forest is a supervised learning algorithm (works on labeled dataset) that is used in both the prediction of both regression and classification problems. 
Our model of predicting radio-sensitivity in breast cancer patients using the random forest algorithm resulted with 70% accuracy and 75% precision.
